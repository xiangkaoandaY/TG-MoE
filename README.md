# TG-MoE

PyTorch implementation of **TG-MoE**, a time-gated mixture-of-experts watermarking method for Stable Diffusion 3 (SD3).

This README only covers the main files required for training and evaluation.

## Main Files

```text
stage1/train.py                              Train the latent watermark encoder and extractor
stage2/SD3LORA2\_temporal\_widepath.py         Train the TG-MoE watermark adapters
stage2/lora\_moe\_temporal\_widepath.py         TG-MoE layers, routing, and temporal gating
stage2/eval\_eval.py                          Generate images and evaluate BitAcc/PSNR/SSIM/CLIP/FID
stage2/blackbox\_ownership\_verify.py           Calibrate and perform black-box ownership verification
stage2/tgmoe\_whitebox\_suite.py                Run white-box robustness experiments
```

## Data and Checkpoints

Stage 1 expects separate training and validation directories containing `.jpg` or `.png` images:

```text
data/stage1/train/
data/stage1/val/
```

Stage 2 expects an image directory with a `metadata.jsonl` file:

```text
data/stage2/
├── image\_00000.jpg
├── image\_00001.jpg
└── metadata.jsonl
```

Each line of `metadata.jsonl` must use the following format:

```json
{"file\_name": "image\_00000.jpg", "text": "A high quality photo of a landscape"}
```

Before Stage 2, prepare the following Stage-1 watermark files:

```text
pretrainedWM/
├── decoder.pth
├── encoder.pth
├── secret.pt
└── wm\_residual.pt
```

`secret.pt` stores the fixed 48-bit owner message. `wm\_residual.pt` stores the corresponding latent residual generated by the trained Stage-1 encoder.

## Stage 1: Train the Watermark Extractor

Run from the repository root:

```bash
CUDA\_VISIBLE\_DEVICES=0 accelerate launch --mixed\_precision=bf16 stage1/train.py \\
  --train\_path data/stage1/train \\
  --validation\_path data/stage1/val \\
  --sd\_model /path/to/stable-diffusion-3-medium-diffusers \\
  --output\_dir outputs/stage1 \\
  --secret\_size 48 \\
  --num\_steps 20000 \\
  --batch\_size 1 \\
  --validation\_batch\_size 1 \\
  --lr 2e-4 \\
  --save\_freq 1000 \\
  --validation\_freq 500
```

The encoder and decoder checkpoints are saved under:

```text
outputs/stage1/saved\_models/
outputs/stage1/checkpoints/
```

## Stage 2: Train TG-MoE

```bash
CUDA\_VISIBLE\_DEVICES=0 accelerate launch --mixed\_precision=bf16 \\
  stage2/SD3LORA2\_temporal\_widepath.py \\
  --pretrained\_model\_name\_or\_path /path/to/stable-diffusion-3-medium-diffusers \\
  --instance\_data\_dir data/stage2 \\
  --pretrainedWM\_dir pretrainedWM \\
  --secret\_pt\_path pretrainedWM/secret.pt \\
  --wm\_residual\_path pretrainedWM/wm\_residual.pt \\
  --output\_dir outputs/tgmoe \\
  --num\_experts 4 \\
  --rank 32 \\
  --loss\_t\_threshold 0.1 0.6 \\
  --train\_batch\_size 1 \\
  --gradient\_accumulation\_steps 4 \\
  --gradient\_checkpointing \\
  --learning\_rate 2e-4 \\
  --max\_train\_steps 20000 \\
  --checkpointing\_steps 500 \\
  --validation\_steps 500
```

The trained transformer is saved at:

```text
outputs/tgmoe/checkpoint-20000/transformer/
```

To resume training, append:

```bash
--resume\_from\_checkpoint latest
```

## Main Evaluation

&#x20;run:

```bash
CUDA\_VISIBLE\_DEVICES=0 python stage2/eval\_eval.py \\
  --base\_model /path/to/stable-diffusion-3-medium-diffusers \\
  --transformer\_dir outputs/tgmoe/checkpoint-20000/transformer \\
  --pretrainedWM\_dir pretrainedWM \\
  --clip\_dir /path/to/clip-vit-base-patch32 \\
  --num\_experts 4 \\
  --rank 32 \\
  --seed 42
```

Generated clean and watermarked images are saved under `Evaluation/noWM/` and `Evaluation/WM/`.

## Black-Box Ownership Verification

First calibrate the ownership thresholds using watermarked and clean outputs:

```bash
CUDA\_VISIBLE\_DEVICES=0 python stage2/blackbox\_ownership\_verify.py benchmark \\
  --vae\_path /path/to/stable-diffusion-3-medium-diffusers \\
  --decoder\_path pretrainedWM/decoder.pth \\
  --secret\_path pretrainedWM/secret.pt \\
  --positive TGMOE=Evaluation/WM \\
  --negative SD3=Evaluation/noWM \\
  --query\_budgets 1,5,10,20 \\
  --num\_trials 2000 \\
  --target\_fpr 0.000001 \\
  --output\_dir outputs/blackbox
```

Verify a folder of images generated by a suspicious model or API:

```bash
CUDA\_VISIBLE\_DEVICES=0 python stage2/blackbox\_ownership\_verify.py verify \\
  --vae\_path /path/to/stable-diffusion-3-medium-diffusers \\
  --decoder\_path pretrainedWM/decoder.pth \\
  --thresholds outputs/blackbox/frozen\_thresholds.json \\
  --suspect\_images /path/to/suspect/images \\
  --query\_budget 10 \\
  --output\_dir outputs/verification
```

## White-Box Robustness Evaluation

```bash
CUDA\_VISIBLE\_DEVICES=0 python stage2/tgmoe\_whitebox\_suite.py \\
  --experiment parameter\_robustness \\
  --base\_model /path/to/stable-diffusion-3-medium-diffusers \\
  --transformer\_dir outputs/tgmoe/checkpoint-20000/transformer \\
  --pretrainedWM\_dir pretrainedWM \\
  --num\_experts 4 \\
  --rank 32 \\
  --num\_prompts 50 \\
  --output\_dir outputs/whitebox
```

Available white-box experiments are:

```text
expert\_dropout
routing\_ablation
adapter\_dropout
parameter\_robustness
routing\_profile
layer\_contribution
```

## Notes

* The default implementation uses a 48-bit secret, four experts, and LoRA rank 32.
* The recommended watermark-active interval is `0.1–0.6` during training.
* SD3 training is memory intensive. Use BF16 and gradient checkpointing when supported.
* Replace every `/path/to/...` placeholder with a valid local path before running.
